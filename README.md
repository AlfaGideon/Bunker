# Bunker

Проект игры «Бункер». Добавлен исходный локальный 3D-прототип Godot: комната, персонажи, раскрытие карточек и тестовое исключение. Проверки Godot и первая Android-сборка успешно выполнены в GitHub Actions; тест на физическом телефоне ещё предстоит.

**Запуск:** импортировать `project.godot` в Godot 4.5.1 и нажать F5. [Инструкция и ограничения](docs/RUNNING.md). [Подсчёт голосов, тесты и подготовка Android APK](docs/BUILD_STATUS.md).

Направление прототипа: Godot 4, стилизованное 3D с камерой сверху под углом и карточным 2D-интерфейсом; целевая платформа — Android. Подключены 3D-модели Quaternius (CC0); источники и лицензии — в [THIRD_PARTY.md](THIRD_PARTY.md).

## Текущий APK — 0.13: постоянная подпись и проверка обновлений

[**Скачать bunker-13.apk напрямую**](https://github.com/AlfaGideon/Bunker/releases/download/android-13/bunker-13.apk) · [Публичный Release](https://github.com/AlfaGideon/Bunker/releases/tag/android-13). Вход в GitHub и распаковка ZIP не нужны.

В приветственном меню и меню партии появилась **«Проверить обновления»**. Приложение проверяет стабильные Releases проекта и предлагает более новую версию. APK скачивается браузером, установку подтверждает Android — тихой установки и автоматической фоновой загрузки нет. Без сети игра работает.

Эта версия впервые опубликована с **постоянным ключом подписи** из GitHub Actions Secrets. При несовпадении подписи прежнюю временную тестовую сборку придётся удалить один раз, с потерей профиля. Дальше обновления с тем же ключом и увеличенным version code устанавливаются поверх приложения; удалять его не нужно.

[**Изменения 0.13**](docs/ITERATION_13.md) · [Обновления, подпись и выпуск следующих версий](docs/ANDROID_UPDATES.md) · [Release workflow](https://github.com/AlfaGideon/Bunker/actions/runs/40690788337) · [Godot CI](https://github.com/AlfaGideon/Bunker/actions/runs/40690788670).

Исходники APK: `0e01f6a`; version code **13**, версия **0.13.0**, APK **59 846 492 байта**. Подпись проверена через apksigner, package ID и код версии — через aapt. Все 14 GDScript-тестов, проверка согласованности версии, четыре визуальные/основные job Godot и release workflow успешны. API latest возвращает ожидаемый `android-13`. Приватных ключей и паролей в исходниках и Release нет.

Сохранены ограниченная камера, полный знак на иконке, отрицательные действия по недостаткам характера и живой лагерь. Один актуальный набор из 16 скриншотов обновлён без накопления версий. Физический BL9000 и переход на следующую подписанную версию ещё требуют испытания.

![Текущее приветственное меню](docs/previews/menu.jpg)

**В самой партии сохранены:** отдельные наружные пристройки и коридоры, профессиональный доступ, совет склада, кухня/еда, две способности, выступления по 60 секунд, выбор d6/d20. Камера управляется свайпом и двумя пальцами, на ПК — мышью и колесом.

**Локальный прототип, не онлайн-игра.** Остальные участники — тестовые фикстуры. Нет чата/микрофона и сохранения партии между запусками. Проверка на физическом BL9000 ещё нужна. При конфликте debug-подписи потребуется удалить прежнюю установку с потерей профиля. [Источники моделей и лицензии](THIRD_PARTY.md).
