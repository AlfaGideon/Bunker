# Bunker

Проект игры «Бункер». Добавлен исходный локальный 3D-прототип Godot: комната, персонажи, раскрытие карточек и тестовое исключение. Проверки Godot и первая Android-сборка успешно выполнены в GitHub Actions; тест на физическом телефоне ещё предстоит.

**Запуск:** импортировать `project.godot` в Godot 4.5.1 и нажать F5. [Инструкция и ограничения](docs/RUNNING.md). [Подсчёт голосов, тесты и подготовка Android APK](docs/BUILD_STATUS.md).

- [Функциональные блоки приложения и правила MVP](FUNCTIONALITY.md)
- [Конкретные ресурсы, движок и порядок их использования](docs/RESOURCES.md)
- [Схема первой анимированной сцены и критерии готовности](docs/FIRST_SCENE.md)
- [Текущая библиотека характеристик и 40 профессий](data/content.json)

Направление прототипа: Godot 4, стилизованное 3D с камерой сверху под углом и карточным 2D-интерфейсом; целевая платформа — Android. Подключены 3D-модели Quaternius (CC0); источники и лицензии — в [THIRD_PARTY.md](THIRD_PARTY.md).

## Текущий APK — 0.14: карточки и бегущая заставка

[**Скачать Bunker-Posledniy-Shlyuz-14.apk**](https://github.com/AlfaGideon/Bunker/releases/download/android-14/Bunker-Posledniy-Shlyuz-14.apk) · [Публичный Release](https://github.com/AlfaGideon/Bunker/releases/tag/android-14).

Приветственное меню переделано: **никакого столбика со скроллом**. Большая карточка «Начать игру» и шесть карточек в сетке, анимированное появление, состояния касания/фокуса. Персонаж и профиль редактируются на отдельной странице с живым предпросмотром у костра.

После старта — отдельная **заставка подготовки**, где выбранный персонаж бежит слева направо с настоящей анимацией Running_A. Модели загружаются в фоне, прогресс соответствует ресурсам. Готовую заставку можно пропустить, подготовку — отменить без создания мира. Сетевого поиска пока нет: интерфейс не выдаёт локальную подготовку за поиск игроков.

Имя приложения в Android — **«Бункер — Последний шлюз»**, имя APK тоже изменено. Сертификат подписи **сравнен и совпал с 0.13**, package ID сохранён. Подписанную 0.13 не нужно удалять: обновление доступно через «Проверить обновления» или по прямой ссылке. В Release оставлена идентичная копия `bunker-14.apk` для совместимости с проверкой обновлений старого клиента.

[**Подробности 0.14**](docs/ITERATION_14.md) · [Обновления и подпись](docs/ANDROID_UPDATES.md) · [Release workflow](https://github.com/AlfaGideon/Bunker/actions/runs/40698411703) · [Godot CI](https://github.com/AlfaGideon/Bunker/actions/runs/40698411601).

Исходники: `2f1ce72`; version code **14**, версия **0.14.0**, APK **59 859 222 байта**. Все 14 GDScript-тестов, проверка согласованности версии, четыре job Godot, Android export и подписанный Release успешны. Тесты проверяют карточки без скролла, бег, отмену подготовки, повторный старт и вход в настоящую партию. Рендеры меню и заставки проверены визуально; единый набор из 16 скриншотов обновлён без накопления версий. Физическая установка 13 → 14 на BL9000 ещё требует проверки.

![Карточки приветственного меню — настоящий рендер Godot](docs/previews/menu.jpg)

**В самой партии сохранены:** отдельные наружные пристройки и коридоры, профессиональный доступ, совет склада, кухня/еда, две способности, выступления по 60 секунд, выбор d6/d20. Камера управляется свайпом и двумя пальцами, на ПК — мышью и колесом.

**Локальный прототип, не онлайн-игра.** Остальные участники — тестовые фикстуры. Нет чата/микрофона и сохранения партии между запусками. Проверка на физическом BL9000 ещё нужна. При конфликте debug-подписи потребуется удалить прежнюю установку с потерей профиля. [Источники моделей и лицензии](THIRD_PARTY.md).
