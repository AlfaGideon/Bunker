# Bunker

Проект игры «Бункер». Добавлен исходный локальный 3D-прототип Godot: комната, персонажи, раскрытие карточек и тестовое исключение. Проверки Godot и первая Android-сборка успешно выполнены в GitHub Actions; тест на физическом телефоне ещё предстоит.

**Запуск:** импортировать `project.godot` в Godot 4.5.1 и нажать F5. [Инструкция и ограничения](docs/RUNNING.md). [Подсчёт голосов, тесты и подготовка Android APK](docs/BUILD_STATUS.md).

- [Функциональные блоки приложения и правила MVP](FUNCTIONALITY.md)
- [Конкретные ресурсы, движок и порядок их использования](docs/RESOURCES.md)
- [Схема первой анимированной сцены и критерии готовности](docs/FIRST_SCENE.md)
- [Текущая библиотека характеристик и 40 профессий](data/content.json)

Направление прототипа: Godot 4, стилизованное 3D с камерой сверху под углом и карточным 2D-интерфейсом; целевая платформа — Android. Подключены 3D-модели Quaternius (CC0); источники и лицензии — в [THIRD_PARTY.md](THIRD_PARTY.md).

## Текущий тестовый APK — 0.12: камера, полный знак и отрицательные действия

[**Скачать ZIP с bunker-debug.apk**](https://github.com/AlfaGideon/Bunker/actions/runs/40684852932/artifacts/12815035009) (нужен вход в GitHub; хранение 14 дней).

- **Камера ограничена по всей видимой области**, а не только по центру. Масштаб 7–40, безопасные границы панорамирования и дополнительный расчёт углов широкого экрана не дают увидеть край площадки. Исправлена также нижняя полоса от ближней плоскости отсечения при отдалении. Свайп и щипок сохранены.
- **Иконка APK теперь содержит весь выбранный знак**, а не отдельно вырезанную дверь. Для адаптивных Android-иконок знак помещён в безопасную область, чтобы круглая маска не срезала буквы. Логотип меню и заставки сохранён.
- **Отрицательные действия** доступны только при конкретном недостатке характера: ссора для вспыльчивого, порча спрятанных рационов для эгоистичного, пропуск обслуживания для небрежного/упрямого. Реально уменьшаются общие запасы. Нужны подтверждение и раскрытие недостатка группе; одно действие за раунд. Профессия или заболевание сами по себе доступ не дают.

Сохранены живой лагерь с моделями Quaternius, ветер, огонь, настройка внешности, профиль и все положительные активности.

[**Подробности 0.12**](docs/ITERATION_12.md) · [Черновик предложения о сотрудничестве](docs/COOPERATION_PROPOSAL_RU.md) · [Godot CI](https://github.com/AlfaGideon/Bunker/actions/runs/40684853007) · [Android build](https://github.com/AlfaGideon/Bunker/actions/runs/40684852932).

Исходники APK: `6f539b3`; version code 12, `0.12.0-character-actions`, ZIP **64 271 689 байт**. Все 13 тестовых скриптов, четыре job Godot workflow и Android export успешны. Проверены настоящая кнопка и подтверждение отрицательного действия, реальные списания и ограничения камеры при 2460×1080. Это проверки в движке; физический BL9000 ещё требует испытания. В проекте один актуальный набор из 16 скриншотов, без архивов версий.

![Текущий бункер — настоящий рендер Godot](docs/previews/bunker.jpg)

**В самой партии сохранены:** отдельные наружные пристройки и коридоры, профессиональный доступ, совет склада, кухня/еда, две способности, выступления по 60 секунд, выбор d6/d20. Камера управляется свайпом и двумя пальцами, на ПК — мышью и колесом.

**Локальный прототип, не онлайн-игра.** Остальные участники — тестовые фикстуры. Нет чата/микрофона и сохранения партии между запусками. Проверка на физическом BL9000 ещё нужна. При конфликте debug-подписи потребуется удалить прежнюю установку с потерей профиля. [Источники моделей и лицензии](THIRD_PARTY.md).
