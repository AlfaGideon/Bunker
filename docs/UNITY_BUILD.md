# Сборка экспериментального Unity APK

Workflow `Unity Android prototype APK` собирает только существующий прототип,
не готовую игру. APK имеет отдельный ID `org.bunker.unityprototype`, debug-подпись
и не заменяет установленный Godot APK. Подписанный релиз и сайт обновлений не
изменяются. Артефакт появляется в результатах успешного запуска GitHub Actions.

Для CI требуется лицензия Unity. Бесплатная Unity Personal подходит при выполнении
условий Unity. Настройте активацию в соответствии с официальной инструкцией
[GameCI](https://game.ci/docs/github/activation/) непосредственно через настройки
репозитория. Не отправляйте данные входа или лицензию в чат и не добавляйте их в
файлы проекта. Без настройки лицензии workflow выдаёт предупреждение и пропускает
сборку — это **не успешная сборка APK**.

После настройки запустите workflow на ветке `arena/574beb82-bunker` или внесите
изменение в `unity/BunkerUnity/`: успешный Android job должен приложить APK к run.
Первый запуск может обнаружить ошибки импорта или компиляции в настоящем Unity;
проверки .NET с заглушками их не заменяют. Пользоваться им как готовой игрой,
сравнивать графику или производительность с Godot до полноценного переноса нельзя.
