# 0.25 — обновление внутри приложения

Экран обновлений скачивает APK во внутреннюю папку приложения, показывает прогресс и проверяет размер и SHA-256 из опубликованного релиза (или SHA256SUMS), прежде чем предложить «Обновить». При ошибке файл удаляется и можно повторить скачивание. Установка открывается через системный установщик Android и встроенный FileProvider Godot, без браузера. Android может попросить разрешить установку из этого источника; после выдачи разрешения, если установка не продолжилась, нужно снова нажать «Обновить». Подтверждение установки остаётся за пользователем.

Подпись и идентификатор приложения сохраняются. Проверка релизной сборки сверяет сертификат с прошлой версией и проверяет наличие REQUEST_INSTALL_PACKAGES в манифесте. Автотест скачивает реальный APK предыдущего релиза через HTTPRequest с перенаправлением и проверяет его размер и SHA-256. Установка на физическом Android-устройстве пока не проверена.

Версия 0.24 ещё использует старый механизм обновления, поэтому для перехода на 0.25 её APK нужно установить прежним способом. Встроенное скачивание заработает при следующих обновлениях из 0.25 и новее.
