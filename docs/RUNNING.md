# Запуск локального прототипа — 0.14

## Исходники

1. Установить **Godot 4.5.1 Standard** (GDScript, без .NET).
2. Импортировать корневой `project.godot` и нажать F5.
3. Откроется отдельное приветственное меню с анимированным персонажем у костра — партия ещё не создана. В нём настроить имя, внешность/оттенок одежды; через «Параметры партии» выбрать 6/8/10 участников и катастрофу. Профиль/настройки сохраняются; сама партия — нет.
4. Нажать «Начать партию»: настройки сохранятся, загрузится бункер и откроется аварийная сводка. Профессии сразу публичны; при раскрытии биологии внешность определяется её полом и возрастом.

## Управление

[Версия 0.14](ITERATION_14.md): приветственный экран теперь из карточек без скролла. «Персонаж» открывает имя, модель и одежду; «Начать игру» — подготовку с бегущим персонажем. После загрузки можно нажать «Войти сейчас» или дождаться автоматического перехода. «Вернуться к костру» отменяет вход без создания бункера. При уменьшенных эффектах перемещение бегуна и анимация появления карточек отключены. Подписанная 0.13 может получить 0.14 через проверку обновлений без удаления приложения.

[Подписанная версия 0.13](ITERATION_13.md) скачивается как APK напрямую из Release. «Проверить обновления» находится в приветственном меню и меню партии; скачивание через браузер, установка с подтверждением Android. Для однократного перехода с прежней временной подписи может потребоваться удаление старой установки с потерей профиля. [Инструкция](ANDROID_UPDATES.md).

[Изменения 0.12](ITERATION_12.md): зум и панорамирование ограничены безопасной областью земли. «Отрицательные действия» находятся на правой панели и в меню партии; они требуют конкретного недостатка характера и подтверждения. Болезнь/инвалидность доступ не открывает. При использовании недостаток раскрывается группе; одно действие за раунд. Иконка приложения содержит полный выбранный знак.

[Логотип, модели лагеря и ветер 0.11](ITERATION_11.md). Если включено «Уменьшить эффекты, ветер и искры», деревья не качаются и частицы отключены — это намеренный режим.

[Приветственное меню, профиль и заставка 0.10](ITERATION_10.md). Смену модели и одежды видно прямо в лагере; сохранение профиля не является сохранением партии.

**Камера:** один палец — перетаскивание; два — масштаб и перетаскивание; короткое касание без свайпа — команда персонажу. На ПК — мышь и колесо. [Подробности 0.9](ITERATION_09.md).

**В 0.8 кухня, склад, медотсек и дополнительные секции — отдельные наружные пристройки.** В меню помещений кнопки «Осмотреть» приближают их; слева «Общий вид бункера» возвращает обзор. [Архитектура и реальные рендеры](ITERATION_08.md).

- Касание свободного пола — маршрут с обходом мебели. Кнопка меню — в углу; меню приостанавливает локальное движение и таймер.
- Справа — выбор досье, дополнительной карты, раскрытие, переход между этапами. Слева — две одноразовые способности, текущая речь и передача хода, совет склада.
- На выступление каждого — 60 секунд. После полного круга — обсуждение, затем тестовое голосование; при ничьей есть переголосование.
- «Помещения и предметы»: выбрать исполнителя, затем действие. Работать может только подходящая профессия, список виден в меню. Радио, еда и койки универсальны. Назначенный участник идёт к предмету.
- Кухня расходует запасы и готовит порции. Совет отдельно решает открытие склада строгим большинством: склад разрешено не открывать всю партию.
- У терминала уже есть один аварийный ремонтный набор. Техническая профессия восстанавливает систему, со второго раунда открывается постоянный медблок.
- При изгнании ваш персонаж проходит шлюз. Выбирайте d6/d20 и выигрышную половину чисел **до** единственного броска. Панель прокручивается. Затем можно продолжить наблюдателем.

## Автоматические проверки

В GitHub Actions закреплён Godot 4.5.1. Оба workflow запускают двенадцать тестовых скриптов; дополнительно Godot workflow делает smoke test и реальные графические рендеры, в том числе широкого окна 2460×1080. Локально, при установленном Godot:

```bash
bash tools/check_godot.sh --headless --editor --path . --quit
for test in tools/test_*.gd; do
  bash tools/check_godot.sh --headless --path . --script "$test" || exit 1
done
```

Проверка широкого framebuffer и растянутого HUD не заменяет тест касаний, безопасных областей, звука и производительности на физическом BL9000.

## Ограничения

Это **локальный прототип**, не сетевая партия. Остальные участники — явные тестовые фикстуры; вы задаёте их голоса и поручения. Нет чата, голосовой связи, интеллектуальных ботов, авторитетного сервера, сохранения партии и защиты скрытых карт от локального клиента. Шкала бодрости детально реализована у вашего персонажа; ресурсы здоровья общие. Оружие пока только инвентарь. Системной русской озвучке нужен установленный Android TTS-голос.

APK складывается в игнорируемую папку `builds/`, распространяется как GitHub Actions artifact. Release-ключи и пароли в Git не хранятся. Debug-подпись runner может отличаться между сборками: при конфликте подписи потребуется удалить прежнее приложение с потерей локального профиля.
