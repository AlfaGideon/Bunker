# Запуск первого визуального прототипа

## Что уже есть

Исполняемый исходный проект Godot: `project.godot`, `game/main.tscn`, `game/scripts/main.gd`.

Сцена строится программно: объёмная комната, стол, терминал, запасы, шлюз, четыре цветных персонажа, ортографическая камера. Есть покачивание персонажей, движение Алекса по переднему проходу и анимация двери. Карточки читаются из `data/prototype.json`.

Это **локальная визуальная демонстрация**, а не реализация всех правил FUNCTIONALITY.md. Исключение выбранного персонажа — ручная тестовая операция, не реальный подсчёт голосов. Нет чата, серверных таймеров, сети, ботов, навигации вокруг мебели и полного набора характеристик. Движение ограничено свободным передним проходом. Сведения всех персонажей находятся в локальном JSON — это не система защиты секретов.

## Как открыть

1. Установить стабильный Godot 4 со стандартным GDScript (не требуется .NET).
2. Импортировать корневой `project.godot`.
3. Нажать F6 для сцены или F5 для проекта.
4. Выбрать карту Алекса и раскрыть её. Остальные тестовые персонажи откроют по одной карте автоматически.
5. Нажать «Следующий этап», выбрать другого персонажа, нажать «Тест: исключить выбранного».
6. Повторить во втором раунде: останутся двое, шлюз откроется.
7. Нажатие на пол перемещает Алекса в пределах переднего прохода.

Интерфейс рассчитан на горизонтальный экран 1280×720; для Android требуется отдельно проверить масштабирование, безопасные области и касания на реальном устройстве.

## Проверки в среде разработки

28 октября 2026 года импорт, 11 проверок правил, headless запуск и экспорт Android APK успешно выполнены в GitHub Actions. Локальная загрузка движка остаётся заблокированной, но сборка перенесена на runner GitHub. Ссылки и инструкция установки — в [BUILD_STATUS.md](BUILD_STATUS.md).

Визуальный запуск на телефоне ещё не проверен. Успех сборки не гарантирует корректную компоновку на каждом устройстве.

## Этап Android-сборки

Нужно установить и закрепить одну версию Godot с соответствующими export templates, установить совместимые JDK и Android SDK, создать Android export preset с package ID, выполнить debug export и установить APK на устройство. Версии инструментов выбираются по документации закреплённой версии Godot, а не произвольно.

Не хранить release-ключи и пароли в Git. При локальной сборке APK складывать в игнорируемую папку `builds/` и распространять отдельно. Наличие `project.godot` само по себе не означает готовность Android-сборки.
