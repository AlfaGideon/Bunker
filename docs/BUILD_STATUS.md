# Проверки и APK

**Текущая версия 0.51.1:** [APK](https://github.com/AlfaGideon/Bunker/releases/download/android-52/Bunker-Posledniy-Shlyuz-52.apk), [Release](https://github.com/AlfaGideon/Bunker/releases/tag/android-52), [подробности](ITERATION_51.md). Version code 52, package `org.bunker.prototype`, подпись совпадает с 0.50. У костра появилась большая плазменная панель из Blender — она стоит за костром и персонажем, перед соснами, как рекламный баннер. Экран живой: заставка логотипа, когда контента нет, аниме «Огни мёртвого города» и пустой рекламный блок под будущие ролики; переключает ведущий, а в бункере — профессия кинотеатра. Добавлены три профессии с нарисованными карточками: Киномеханик, Билетёр, Киновед; сеанс в зале даёт команде +6 бодрости раз в раунд. Физическая установка на BL9000 ещё нужна.

**Историческая версия 0.50:** [APK](https://github.com/AlfaGideon/Bunker/releases/download/android-50/Bunker-Posledniy-Shlyuz-50.apk), [Release](https://github.com/AlfaGideon/Bunker/releases/tag/android-50), [подробности](ITERATION_50.md). Version code 50, package `org.bunker.prototype`, подпись совпадает с 0.49. Бункер обзавёлся пристроенными комнатами: операционная крепится к медотсеку и открывается, когда в команде есть врач или фельдшер, кладовая крепится к кухне и открывается повару, санузел открыт всем. Комнаты соединяются с модулями коротким коридором, у каждой своя дверь с табличкой, проверка доступа идёт на старте и после каждого раунда, закрытая комната непроходима. Койки заменены моделью из Blender с изголовьем на короткой стороне. В санузле — унитаз, раковина и звуки: смыв, смешок и пук, синтезированные `tools/generate_sfx.py`. Снаружи теперь рельеф: поле шума с дюнами, ровная площадка вокруг бункера и валуны из Blender, трава и камни стоят на земле, а не висят. Физическая установка на BL9000 ещё нужна.

**Историческая версия 0.49:** [APK](https://github.com/AlfaGideon/Bunker/releases/download/android-49/Bunker-Posledniy-Shlyuz-49.apk), [Release](https://github.com/AlfaGideon/Bunker/releases/tag/android-49), [подробности](ITERATION_49.md). Version code 49, package `org.bunker.prototype`, подпись совпадает с 0.48. Станции из Blender ожили: у приёмника при смене записи поворачиваются три латунные ручки, стрелка переезжает по шкале, а шкала коротко вспыхивает; у терминала курсор шагает по строкам и мигает, экран мерцает; над котлом на кухне поднимается и гаснет полупрозрачный пар (`alphaMode: BLEND`). Для этого ручки, стрелка, курсор и пар выгружаются отдельными узлами glTF, а `game/scripts/station_motion.gd` двигает их в игре. Чернильный контур теперь ребёнок своего меша, иначе оболочка отставала от крутящейся ручки. Новый `tools/test_station_motion.gd` проверяет, что всё это действительно двигается. Физическая установка на BL9000 ещё нужна.

**Историческая версия 0.47:** [APK](https://github.com/AlfaGideon/Bunker/releases/download/android-47/Bunker-Posledniy-Shlyuz-47.apk), [Release](https://github.com/AlfaGideon/Bunker/releases/tag/android-47), [подробности](ITERATION_47.md). Интерактивные пропсы переделаны в Blender и стилизованы: приёмник на общем столе (латунные ободы динамиков, янтарная шкала, лампа, антенна), кухонный пост (плита со светящимся кольцом, открытый котёл с варевом, половник, миски, жестянки, пар), настенный медшкаф с тремя полками склянок, тёплой лампой и распахнутой дверцей с крестом, консоль с наклонным CRT, бирюзовым экраном со строками развёртки и клавиатурой. Превью рендерит сам Blender, игровой кадр — `STATIONSHOT`. [Подробности](ITERATION_47.md).

## Что проверяет прототип

Объёмная комната, камера сверху, простые анимированные персонажи, перемещение в переднем проходе, своё и публичное досье, раскрытие карт, два тестовых исключения и открытие шлюза.

Голоса остальных участников задаются явной тестовой фикстурой, а не ботами или сетью. Модуль `vote_rules.gd` отдельно обрабатывает недопустимые голоса, отсутствие голосов, первый и повторный тур; полный UI второго тура ещё не реализован.

## Установка

1. Скачать ZIP-артефакт и распаковать `bunker-debug.apk`.
2. Открыть APK на Android. При необходимости разрешить установку из этого источника стандартным способом Android; не отключать защиту устройства целиком.
3. Запустить «Бункер — прототип», использовать горизонтальный экран.
4. Раскрыть карту Алекса → «Следующий этап» → выбрать другого участника → «Голосовать (тестовые участники)». Повторить во втором раунде.

Поддерживаются ARM64 и x86_64; ARMv7 не включён. Package ID — `org.bunker.prototype`. Это debug-сборка с временным ключом runner: последующие сборки могут требовать удаления предыдущей установки. Для постоянного распространения нужен сохраняемый ключ подписи, не в Git.

## Автоматизация

- `.github/workflows/godot.yml` — импорт, проверки правил и headless запуск.
- `.github/workflows/android.yml` — APK на push в рабочую ветку и ручной запуск, export templates, Android SDK, debug-подпись, загрузка артефакта.
- `export_presets.cfg` — экспорт Android; JSON включён явно.

Остаются: тест APK на устройстве, исправления по отзывам, полноценный автомат фаз, текстовый чат и авторитетный сетевой сервер. Локальный JSON не защищает секреты и не должен целиком раздаваться сетевым клиентам.
