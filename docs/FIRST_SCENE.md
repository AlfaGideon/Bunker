# Первая сцена: «Последний шлюз»

Статус: спецификация целевой сцены. Добавлена начальная программно создаваемая сцена `game/main.tscn`; запуск движком пока не подтверждён. Реализовано лишь подмножество требований; ограничения перечислены в [RUNNING.md](RUNNING.md).

```text
                   СЕВЕР
┌───────────────────────────────────────┐
│ Закрытая часть убежища                 │
│ [медпункт] [жилой отсек] [генератор]    │
├────────────── ГЕРМОДВЕРЬ ──────────────┤
│                                       │
│      ○       ○       ○                │
│         ПЕРЕГОВОРНЫЙ СТОЛ   [терминал] │
│      ○       ○       ○                │
│                                       │
│           ВХОД / ЗОНА ОЖИДАНИЯ         │
└───────────────────────────────────────┘
```

Начинаем только с зоны ожидания. Остальные помещения — видимые закрытые декорации, без симуляции ресурсов. Основные правила не меняем: события и эпилог из обсуждения не считаются согласованным расширением FUNCTIONALITY.md.

## Предлагаемое дерево Godot

```text
Game (Node3D)
├── Environment (WorldEnvironment)
├── CameraRig (Node3D)
│   └── Camera3D (orthogonal)
├── Bunker (Node3D)
│   ├── Floor (StaticBody3D + MeshInstance3D + CollisionShape3D)
│   ├── Walls (Node3D)
│   ├── Table (StaticBody3D)
│   └── Door (Node3D + AnimationPlayer)
├── Survivors (Node3D)
│   └── Survivor (CharacterBody3D + CollisionShape3D + MeshInstance3D)
└── HUD (CanvasLayer)
    ├── PhaseHeader (этап, раунд, таймер)
    ├── DossierPanel (свои карты)
    ├── PublicCardsPanel (раскрытые карты других)
    ├── VotePanel (кандидаты)
    └── DemoNotice (пометка локальной демонстрации)
```

## Взаимодействия и анимация

- Нажатие на пол задаёт цель движения. Стены и стол непроходимы.
- Выбор персонажа открывает только публичное досье.
- Своя закрытая карточка доступна владельцу; раскрытие переносит её в публичную область с короткой анимацией.
- На этапе голосования UI предлагает допустимых кандидатов, исключая себя и выбывших.
- Гермодверь открывается в финале. Анимация не определяет результат голосования.
- Во время обсуждения — спокойные idle-анимации и подсветка выбранного персонажа.
- UI не требует подходить к столу; информация доступна независимо от позиции персонажа.

## Минимальный локальный сценарий

Четыре тестовых персонажа, два места, одна катастрофа. Пользователь управляет одним персонажем. Для остальных — явно обозначенные тестовые действия, а не имитация настоящих онлайн-участников. Демонстрация не должна заявляться как полноценная партия с ботами.

Данные: [data/prototype.json](../data/prototype.json). Это фикстура для разработки; весь набор лежит локально, поэтому она не обеспечивает приватность и не должна передаваться целиком клиентам сетевой игры.

## Приёмка реализации

- Сцена запускается без отсутствующих ресурсов.
- Камера показывает стол и всех четырёх персонажей.
- Персонаж перемещается, не проходя сквозь препятствия.
- Собственное досье видно, чужие нераскрытые поля не отображаются.
- Раскрытая карточка появляется в публичном списке.
- Голос за себя и выбывшего недоступен.
- Можно пройти два исключения и увидеть двух оставшихся.
- Для ничьей и отсутствия голосов соблюдаются правила FUNCTIONALITY.md.
- Новый запуск демонстрации восстанавливает исходное состояние.
- На Android отдельно проверены читаемость UI, касания и производительность.

Ни один пункт пока не отмечен выполненным: это задачи следующего этапа, не отчёт о готовой игре.
