# 0.32 — уменьшение APK без отката игры

В Android-экспорте Godot включено `gradle_build/compress_native_libraries`: библиотеки движка упаковываются со сжатием, как в APK 0.28–0.29. Код игры и ресурсы из 0.31 остаются без отката; поддержка ARM64 и x86-64 сохранена.

Gradle-экспорт остаётся включён для Android-манифеста с запросом видимости системных TTS-движков. Сжатые библиотеки Android извлекает при установке; уменьшение размера скачиваемого APK не означает такое же сокращение занятого места после установки.

Автопроверки проверяют наличие обеих библиотек и их сжатие, а релизный workflow также проверяет разрешение установщика, запрос системного TTS, package ID и сертификат в сравнении с прошлым выпуском. Тест на физическом устройстве не проводился.
