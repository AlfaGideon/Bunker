# 0.38 — приглашения и тест с ботами

Вид от первого лица включается при входе в игру; вид сверху доступен прежней кнопкой. В полном лобби, состоящем только из ведущего и тестовых ботов, ведущий может запустить локальную партию с именами и внешностью из комнаты. Остальные люди не могут запустить этот режим. Это не сетевая игра: синхронизации состояний и полноценного ИИ нет, а выход ведущего закрывает лобби.

Страница приглашения использует собственный фон и потоковый `/download`: сервер получает актуальный подписанный релиз из фиксированного GitHub-репозитория и передаёт APK частями, не буферизуя его в память. Проверено скачивание целого APK в GitHub Actions. Бесплатный хостинг может ограничивать трафик, время запроса и пробуждение; требуется проверка на конкретном развёрнутом контейнере. Комнаты хранятся в памяти и исчезают после перезапуска. Android-устройство для ручного теста недоступно.
