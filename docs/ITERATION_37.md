# 0.37 — сервер SnapDeploy

Адрес лобби по умолчанию изменён на `wss://bunker-154de.containers.snapdeploy.app/ws`; ссылки-приглашения используют тот же хост. Бесплатный SnapDeploy отклоняет WebSocket (при проверке получен HTTP 403), поэтому для этого хоста клиент и сервер поддерживают обмен обычными HTTPS-запросами с коротким опросом. Для других серверов сохранён WebSocket. Серверная часть должна быть развёрнута из этой версии кода: прежний контейнер не поддерживает новый протокол.

Тесты проверяют HTTPS-сессии, совместимость с WebSocket-клиентом, приглашения и ботов. Сетевой режим остаётся тестом лобби: онлайн-партия не синхронизирована. В работе бесплатного тарифа возможны паузы при засыпании и лимиты. На физическом Android версия не проверялась.

Публичный SnapDeploy после развёртывания проверен автоматическим тестом: шесть отдельных HTTPS-сессий, приглашение, добавление и удаление бота, ограничения по запуску для ведущего и общего количества. Физические телефоны не проверены.
