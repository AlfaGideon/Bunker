# Бункер — экспериментальный перенос на Unity

Это **начальный прототип сетевого протокола и автономных раундов**, не замена текущей игры. Существующие Godot-проект, APK и сервер не изменены. Прототип отображает комнаты, присоединение, ботов, речи, характеристики, голоса и серверные команды станций в тестовом карточном интерфейсе. Он использует существующий HTTPS polling `/transport/*` и сервер `server/app.py`, не раскрывая секреты других игроков и не рассчитывая игровые правила на клиенте.

## Открытие и сборка

Нужен установленный Unity Editor 2022.3.62f1 с модулем Android Build Support и действующей лицензией Unity. Откройте папку `unity/BunkerUnity` как проект Unity; дождитесь импорта и откройте `Assets/Scenes/Bootstrap.unity`. В Play Mode доступны локальные HTTP-адреса для теста; на устройстве требуется HTTPS. Для тестовой сборки выберите `Bunker → Build prototype Android APK`. У неё отдельный идентификатор `org.bunker.unityprototype`, она **не обновляет и не заменяет** рабочее приложение Godot. Production-ключи не используются и не хранятся в проекте.

## Уже перенесено в коде

- HTTPS-сессия, очередь команд, опрос событий, создание/поиск/подключение по коду, боты и запуск матча на существующем сервере.
- Персонализированные снимки, карточки, раскрытие, передача хода и голосование.
- Сетевые команды еды, отдыха, помещений и радио; результаты отображаются только после ответа сервера.
- Автономный тест: раздача 6/8/10, случайные боты, речи, обсуждение и голосование без сервера. В карточном режиме добавлены правила еды, отдыха, врачебного допуска, запасы и их расход, кухня, мастерская, теплица, зал, терминал, склад и текстовые передачи радио. Это не полная локальная игра: геометрии комнат пока нет.
- Для локальных и сетевых снимков радио добавлены четыре оригинальных трека «Авроры» (CC0) и Android TTS для новых текстовых передач и маяка. При отсутствии русского голоса текст остаётся видимым; старые сообщения повторно не озвучиваются. Это код прототипа, Android-проверки ещё не было.
- В проект скопированы существующие игровые JSON и полный логотип; исходные файлы Godot сохранены.

## Ещё не перенесено / не проверено

- 3D-сцены, красивый бункер, лагерь, персонажи, анимации, камера, сенсорная ходьба и вид сверху.
- Полноценная локальная игра без интернета: геометрия и доступ к помещениям, способности, изгнание и выживание, физические взаимодействия и анимации. Также не перенесены профиль/скины, библиотека характеристик, эффекты катастроф, прочие игровые звуки, интернет-радио и полноценный голосовой помощник, приглашения, обновление APK и сохранения.
- Полноценная синхронизация движения и остальных игровых систем — этих возможностей нет в текущем сервере.
- Прототип собран в Unity 2022.3.62f1 на GitHub Actions, целостность APK, debug-подпись, package ID и наличие Java-моста проверены. Рабочая среда агента не содержит Unity, а сам APK, сцена, звук и управление ещё не запускались на Android или в Play Mode. Не утверждаем, что прототип уже полностью работает.

Платные ассеты не используются. Содержимое Unity Asset Store не копируется в публичный репозиторий без проверки условий. Дальше — сначала проверить запуск в Unity и протокол двух реальных клиентов, затем перенести локальные правила и сделать визуальную сцену из разрешённых бесплатных ассетов, сохраняя рабочий Godot APK до достижения паритета.

CI для экспериментальной APK описан в `docs/UNITY_BUILD.md` в корне репозитория.
При отсутствии активации Unity сборка пропускается и APK не создаётся.
